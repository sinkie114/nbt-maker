# NBT Maker

Minecraft 1.21.11 Fabric 客户端物品堆数据调试器。使用、SNBT 格式与构建方法见 [使用说明](使用说明.md)。

1.0.5 客户端网络解码不再校验附魔等级：任意 int 等级都能从服务端同步到客户端，单人同步超范围附魔不再出问题（存档用的 1–255 codec 未改，超范围附魔存档时仍会写不进去）。简单模式“显示信息”新增名称文字/颜色/样式、Lore 逐行编辑、稀有度、染色、物品模型、自定义模型数据、提示框隐藏、附魔光效表单；“容器与物品”新增格子界面，潜影盒/收纳袋/弩装填可直接点格子放入、改数量、删除，并进入内部物品的简单模式继续编辑。

1.0.4 普通附魔和存储附魔支持完整 int 等级（`-2147483648` 至 `2147483647`），负数和零均原样保留。移除旧版对原版附魔编解码器及构造校验的改写，改由编辑器单独构建内存组件；原版保存、读取和网络校验保持原样。

1.0.3 修复附魔添加、删除与等级修改后列表不刷新的问题，并保留搜索和页码。简单模式的“使用与行为”增加食物、食用后效果、冷却、返还物品及药水表单，支持从游戏注册表选择原版和 mod 的状态效果、药水、物品及声音。

1.0.2 默认进入简单模式，可在 GUI 切换高级模式。简单模式的属性修饰符支持搜索原版 / mod 属性、设置数值、选择运算和装备部位、逐条新增和删除。高级模式保留完整数据树，移除了旧组件面板入口。

1.0.1 新增 SEE 1.0.7 联动：F8 查看实体，悬停物品按 X 编辑，点击同步写回真实实体槽位。见 [联动说明](SEE联动说明.md)。
